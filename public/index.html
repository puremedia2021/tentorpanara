Sistem Payroll Tentor

Alur kerja:

  1. Buat data Paket, Tentor, dan Siswa di halaman Master Data.
  2. Input Sesi belajar baru (tempat, jumlah peserta, keterangan) di halaman Input Sesi.
  3. Sistem akan membuat 2 link acc: satu untuk tentor, satu untuk siswa.
  4. Tentor dan siswa membuka link masing-masing, upload foto bukti, lalu klik Acc.
  5. Setelah kedua-duanya acc, sesi otomatis masuk ke Rekap Payroll.
